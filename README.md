# Meta Ads Performance Analysis & Optimisation

## Project Overview
A practical case study documenting my work in Meta Ads performance analysis, lead-generation reporting, and campaign optimisation.

## My Role
Digital Marketing Executive

## Objectives
- Analyse campaign performance and lead-generation costs.
- Identify optimisation opportunities using campaign data.
- Improve reporting and support data-driven decisions.

## Work Performed
- Analysed spend, impressions, clicks, CTR, CPC, and cost per lead (CPL).
- Reviewed audience and location performance where data was available.
- Used campaign insights to inform optimisation recommendations.
- Worked on automating reporting and AI-assisted analysis.
